Key Features
Interactive Side Drawer
A sleek, stowable interface providing quick access to the Roster and Help. It auto-hides when focusing on characters and automatically adjusts roster content seamlessly when moving between map and non-map areas in hybrid rooms.
Map Compass & Sticky Tracking
Hover over a player's Name or ID to display a directional arrow. Mobile/Drawer users: Tap the {{Icon_Compass}} on a player's card to lock the compass to them! Tracking is mutually exclusive and auto-clears when the drawer is stowed.
Smart Performance Scaling
CRABS monitors true frame delta (ignoring manual FPS caps) to detect lag. If performance dips consistently, it dynamically disables the animated logo, reduces blur quality, and lowers update rates to keep your game running smoothly.
Immersive Blindness & BCX Integration
Optional blurring of the roster based on your character's blindness level. Fully respects BCX "Full Blind" rules when enabled.
Core Commands
/roster [argument]
Opens the enhanced roster in the chat log. Shows detailed information about everyone in the room.
Arguments:
• count - Only shows current room population counters.
• admins - Only lists room administrators.
• vips - Only lists room whitelisted users.
• banner - Force redraws the room information banner.
• help - Shows this documentation.
/whisper+ [number] [msg] or /w+
Global whisper system for map rooms. Bypass range restrictions to message anyone on the map.
/dropkeys [color/all]
Instantly drop specific keys (bronze, silver, gold) or all keys at once.
Interactions & Navigation
  • Click Badge or Name: Opens the character's focus screen / Whisper+.
  • Click Number (ID): Copies the player's member number to your clipboard.
  • Hover Name or ID: Activates the temporary Map Compass.
  • Fast "Back to Chat": In the CRABS settings menu, use the "To Chat" button to instantly exit menus without spamming the back button.

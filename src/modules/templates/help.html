Key Features
🗄️ Interactive Drawer
A sleek, stowable roster interface. Auto-adjusts in hybrid rooms and hides when focusing characters.
🧭 Sticky Map Compass
Hover names to find players, or click the {{Icon_Compass}} to track them persistently! Auto-clears when stowed.
⚡ Smart Performance
Monitors true frame delta to detect lag. Dynamically lowers visual quality and update rates to save your FPS.
👁️ Immersive Blindness
Optional roster blurring based on your blindness level. Fully respects BCX "Full Blind" rules.
✨ Smart Colors
Automatically detects dark or muddy player name colors and applies a high-contrast outline for readability.
📝 Note to Self
Sending a Whisper+ to your own member number creates a private, grayed-out note in your chat log.
Core Commands
/roster [argument]
Opens the enhanced roster in the chat log. Shows detailed information about everyone in the room.
Arguments:
• count - Only shows current room population counters.
• admins - Only lists room administrators.
• vips - Only lists room whitelisted users.
• banner - Force redraws the room information banner.
• help - Shows this documentation.
/whisper+ [number] [msg] or /w+
Global whisper system for map rooms. Bypass range restrictions to message anyone on the map.
/dropkeys [color/all]
Instantly drop specific keys (bronze, silver, gold) or all keys at once.
Interactions & Navigation
  • Click Badge or Name: Opens the character's focus screen / Whisper+.
  • Click Number (ID): Copies the player's member number to your clipboard.
  • Live Sorting: Use the top-right dropdown in the drawer to sort players by Roles, D/s Family, Lovers, or Friends.

⚙️ Settings Overview
Access settings via the {{Icon_Settings}} icon in the drawer. Tip: Use the "To Chat" button inside the settings menu to instantly return to the game without spamming the back button!
  • Drawer: Toggle the drawer UI entirely, set a compact height, hide the side tab, or enable auto-stowing after you chat or whisper.
  • Immersion: Enable immersive blindness/gags, or respect BCX rules. Enable the Hardcore Lock to prevent changing immersion settings while your character is restrained!
  • Maps: Toggle the directional compass or unlock the game's default zoom limits (SuperZoom).

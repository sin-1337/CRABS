Key Features
🗄️ Interactive Drawer
A sleek, stowable roster interface. Fully event-driven for real-time status updates without the lag.
🧭 Universal Compass & Focus
Track players in maps or normal rooms! Hovering cards, chat names, or characters reveals a spinning 3D indicator and halo glow.
🔔 Chat Highlighting
Highlights messages containing your name or custom words. Includes color matching, auto-capitalization, and exclusion phrases to prevent false positives.
🛡️ Privacy Mode
A customizable "boss key" that instantly blanks the character screen or game window. Toggle via keybind (Default: CTRL + ALT + B).
⚡ Smart Performance
Monitors true frame delta. Dynamically lowers visual quality and update rates to save your FPS during lag spikes.
👁️ Immersive Blindness
Optional roster blurring based on your blindness level. Fully respects BCX "Full Blind" rules.
✨ Smart Colors
Automatically detects dark or muddy player name colors and applies a high-contrast outline for readability.
💬 Whisper+
Send whispers in map rooms at any distance. Auto-elevates to a beep if a friend leaves the room before you send.
Core Commands
/roster [argument]
Opens the enhanced roster in the chat log. Shows detailed information about everyone in the room.
Arguments:
• count - Only shows current room population counters.
• admins - Only lists room administrators.
• vips - Only lists room whitelisted users.
• banner - Force redraws the room information banner.
• help - Shows this documentation.
/whisper+ [number] [msg] or /w+
Global whisper system for map rooms. Bypass range restrictions to message anyone on the map.
/dropkeys [color/all]
Instantly drop specific keys (bronze, silver, gold) or all keys at once.
Interactions & Navigation
  • Click Badge: Opens the character's focus screen.
  • Click Player's Name: Start a Whisper+ message.
  • Click Number (ID): Copies the player's member number to your clipboard.
  • Live Sorting: Use the top-right dropdown in the drawer to sort players by Roles, D/s Family, Lovers, or Friends.
  • Reverse Hover: Hovering a character in the game world highlights their card in the roster.
  • Keyboard Shortcuts: CTRL + ALT + D toggles the drawer. CTRL + ALT + B toggles Privacy Mode.

⚙️ Settings Detailed Overview
Access settings via the {{Icon_Settings}} icon in the drawer, now featuring a fully tabbed interface.
Quick Chat Return: Click the Chat Bubble Icon in the top right to instantly return to the game.
General
  • Update Notifications: Alerts you when to refresh for a new version.
  • Show Banner on Entry: Displays an info banner when joining a room.
  • Full-Screen Privacy Mode: Blanks the entire screen instead of just the chat side when the hotkey is used.
  • Enable Focus Halo: Shows a pulsing halo effect on hovered avatars.
  • Edit Keybinds: Direct shortcut to the game's keybinding menu to change your Privacy and Drawer toggle hotkeys.
Drawer
  • Enable Drawer UI: Turns the sliding drawer interface on or off.
  • /roster toggles drawer: Typing /roster or /crabs opens the drawer instead of printing in chat.
  • Show Drawer Tab: Toggles the persistent visual tab on the screen edge.
  • Animated Tab Logo: Toggle the drawer logo animation to save performance.
  • Compact Height: Limits the drawer to 77% height, keeping the chat input visible.
  • Auto-stow Options: Close the drawer automatically after sending a standard chat or Whisper+.
  • Focus Follows Mouse: Automatically switch to a player's page when hovering their card.
  • Auto-Scroll Drawer: The roster automatically scrolls to the character you are mousing over in the game world.
Immersion
  • Hardcore Lock: Locks these immersion settings ON while your character is bound.
  • Respect Blindness & Gags: Blurs the roster UI and disables Whisper+ based on character state.
  • Respect BCX Rules: Enforces BCX restrictions within the CRABS interface.
Maps
  • Show Map Compass: Displays a directional arrow on the map.
  • SuperZoom: Unlocks the game's default map zoom limitations (auto-disables if conflicts are detected).
Chat
  • Highlight Mentions: Alerts you when specific words or your name are spoken. Customize the highlight color.
  • Auto-Capitalize & Color Match: Capitalizes your name and matches it to your character's label color in highlights.
  • Custom Words & Exclusion Phrases: Add trigger words and use wildcards (e.g., 'pick* a rose') to prevent false alarms.
  • Chat Log Hover Links: Hovering names in the chat log triggers the focus halo and map compass.
  • Whisper+ Auto-elevate: Attempts to send a Whisper+ as a standard beep if a friend leaves the room.
Config
  • Disable Cloud Sync: Keeps settings strictly local, preventing cross-device syncing. Includes a capacity tracker.
  • Delete Server Save: Wipes your CRABS settings from the game server.
  • Export / Import: Copy or paste your settings string to backup or share.

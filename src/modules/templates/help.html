Key Features
🗄️ Interactive Drawer
A sleek, stowable roster interface. Auto-adjusts in hybrid rooms and hides when focusing characters.
🧭 Sticky Map Compass
Hover names to find players, or click the {{Icon_Compass}} to track them persistently! Auto-clears when stowed.
⚡ Smart Performance
Monitors true frame delta to detect lag. Dynamically lowers visual quality and update rates to save your FPS.
👁️ Immersive Blindness
Optional roster blurring based on your blindness level. Fully respects BCX "Full Blind" rules.
✨ Smart Colors
Automatically detects dark or muddy player name colors and applies a high-contrast outline for readability.
📝 Note to Self
Sending a Whisper+ to your own member number creates a private, grayed-out note in your chat log.
Core Commands
/roster [argument]
Opens the enhanced roster in the chat log. Shows detailed information about everyone in the room.
Arguments:
• count - Only shows current room population counters.
• admins - Only lists room administrators.
• vips - Only lists room whitelisted users.
• banner - Force redraws the room information banner.
• help - Shows this documentation.
/whisper+ [number] [msg] or /w+
Global whisper system for map rooms. Bypass range restrictions to message anyone on the map.
/dropkeys [color/all]
Instantly drop specific keys (bronze, silver, gold) or all keys at once.
Interactions & Navigation
  • Click Badge or Name: Opens the character's focus screen / Whisper+.
  • Click Number (ID): Copies the player's member number to your clipboard.
  • Live Sorting: Use the top-right dropdown in the drawer to sort players by Roles, D/s Family, Lovers, or Friends.

⚙️ Settings Detailed Overview
Access settings via the {{Icon_Settings}} icon in the drawer. Quick Chat Return: Click the Chat Bubble Icon in the top right of the settings screen to instantly return to the game.
Banner
  • Show Banner on Entry: Displays a brief information summary when joining a new room.
Drawer
  • Disable Drawer UI: Turns off the sliding drawer entirely. The roster will only print directly in the chat log.
  • /roster toggles drawer: Typing /roster or /crabs opens the drawer instead of printing to the chat window.
  • Hide Drawer Tab: Removes the persistent visual tab on the side of the screen. (Requires commands to open the drawer).
  • Compact Height: Limits the drawer to 77% of the chat window height, ensuring the chat input box remains uncovered.
  • Auto-stow on Whisper+: Automatically closes the drawer after you send a Whisper+ message.
  • Auto-stow on Chat: Automatically closes the drawer when you send a standard chat message.
Immersion
  • Hardcore Lock: Prevents you from disabling active immersion settings while your character is restrained.
  • Respect Blindness: Blurs the roster UI based on your character's current blindness level.
  • Respect Gags: Disables the Whisper+ system if your character is gagged.
  • Respect BCX Rules: Enforces BCX rules (such as "Full Blind" or specific whisper restrictions) within the CRABS interface.
Maps
  • Show Map Compass: Toggle the Compass feature which displays a directional arrow on the map pointing toward tracked player.
  • SuperZoom: Unlocks the game's default map zoom limitations. CRABS will disable this feature if we detect that another mod or script is tampering with it.

# Security Policy

## Supported Versions

| Version |  Status   | Supported          |
| ------- |-----------| ------------------ |
| 3.x.x   |  Beta     | :white_check_mark: |
| 2.x.x   |  Stable   | :white_check_mark: |
| 1.x.x   |  Obsolete | :x:                |

## Reporting a Vulnerability

### How to Report
* **Email:** Send details to `sinthesinner@proton.me` (optionally include your PGP key link).
* **GitLab Issue:** Open an issue in this repository and check the **"This issue is confidential and should only be visible to team members with at least Reporter access"** checkbox.

### What to Include
* A description of the issue and potential impact.
* Step-by-step instructions or proof-of-concept to reproduce the vulnerability.
* Affected versions and environment details.

### Response & Handling
* **Resolution:** A patch for the issue will be pushed as soon as possible.
